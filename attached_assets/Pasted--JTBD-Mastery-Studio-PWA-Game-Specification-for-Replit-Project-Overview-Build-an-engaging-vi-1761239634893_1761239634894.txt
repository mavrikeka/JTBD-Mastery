# JTBD Mastery Studio - PWA Game Specification for Replit

## Project Overview
Build an engaging, visually appealing Progressive Web App that teaches CEOWorks executives and practitioners how to write excellent Jobs-to-be-Done (JTBD) statements. The game must be fun, interactive, and deliver real learning value for busy CFOs and CHROs.

---

## What is JTBD (CEOWorks Context)

At CEOWorks, we help companies identify the 1% of critical roles that deliver 80% of enterprise value. For each critical role, we define 3-5 "Jobs To Be Done" that specify exactly what work must be accomplished.

### The JTBD Formula:
A great JTBD has three mandatory components:

1. **WHAT** - The specific work to be done (action verbs, not vague goals)
2. **HOW MUCH** - Measurable outcomes with before/after metrics  
3. **WHEN** - Clear deadline or timeframe (3-5 year strategic view)

### The "Glass Slipper" Test:
"If you can Google it, it's NOT a JTBD."

JTBDs must be so bespoke and specific that they exclude 95% of candidates—like Cinderella's glass slipper. Generic job descriptions fail.

### Good vs Bad Examples:

❌ **BAD:** "Improve operational efficiency and reduce costs"
- Too vague, no metrics, Googleable, could apply to anyone

✅ **GOOD:** "Redesign manufacturing operations across 8 facilities implementing Six Sigma and predictive maintenance, reducing unplanned downtime from 12% to 3% and increasing overall equipment effectiveness from 65% to 85% by Q4 2026"
- Specific work (redesign + implement Six Sigma)
- Clear metrics (12%→3%, 65%→85%)
- Defined scope (8 facilities)
- Deadline (Q4 2026)

---

## Game Design Philosophy

### Make It Fun & Engaging:
- **Visual delight**: Modern gradients, smooth animations, satisfying interactions
- **Immediate feedback**: Real-time scoring, visual progress indicators
- **Micro-wins**: Celebrate small victories with animations and encouraging messages
- **Clear progress**: Always show where they are and what they've accomplished
- **Mobile-first**: Touch-friendly, swipe gestures, thumb-zone optimization

### Make It Valuable:
- **Practical utility**: Modes solve real problems (blank page, critique existing work)
- **No busywork**: Respect user time, every interaction teaches something
- **AI-powered**: Smart feedback that feels like a coach, not a robot

---

## Three Core Modes

### MODE 1: LEARN (Pattern Recognition)
**Goal:** Train users to recognize good vs bad JTBDs instantly

**Experience:** Tinder-style swipeable cards showing side-by-side comparisons

### MODE 2: BUILD (Guided Creation)  
**Goal:** Solve the "blank page problem" with scaffolded JTBD writing

**Experience:** Step-by-step wizard with AI assistance at each stage

### MODE 3: CRITIQUE (AI Coach)
**Goal:** Improve existing JTBDs with detailed AI feedback

**Experience:** Paste or type JTBD, get instant analysis and suggestions

### Screen 3: Pattern Recognition Quiz

**Format:** Interactive quiz (5 questions)

**Question Types:**

**Type 1: Spot the Flaw**
```
Question: What's wrong with this JTBD?
"Improve sales performance and grow revenue in key markets"

Options:
A) Timeline is missing
B) Not specific about WHICH markets
C) No metrics (how much growth?)
D) All of the above ✓

Feedback: "Correct! This JTBD has multiple problems. It's too vague, 
has no metrics, and could apply to any sales role."
```

**Type 2: Choose the Better JTBD**
```
Question: Which JTBD is more bespoke?

Option A: "Transform operations to reduce costs by 20%"

Option B: "Consolidate 12 distribution centers into 4 regional hubs, 
implement automated inventory management, reducing logistics costs 
from $89M to $71M (20%) by Q2 2026" ✓

Feedback: "Option B wins! It specifies the actual work (consolidation, 
automation) and gives precise metrics with context."
```

**Type 3: Missing Component**
```
Question: What's missing from this JTBD?
"Build enterprise sales team of 25 reps and establish Fortune 500 
sales playbook, growing enterprise ARR from $12M to $45M"

Options:
A) WHAT is missing
B) HOW MUCH is missing
C) WHEN is missing ✓
D) Nothing is missing

Feedback: "No deadline! We don't know if this should happen in 6 months 
or 3 years. Always include WHEN."
```

**Type 4: The Google Test**
```
Question: Can you Google this job description?
"Lead marketing strategy and brand development initiatives"

Options:
A) Yes - it's too generic ✓
B) No - it's specific enough

Feedback: "This would return thousands of similar job postings. 
Not bespoke enough!"
```

**Type 5: Identify the Good Elements**
```
Question: What makes this JTBD strong?
"Redesign customer onboarding process using AI-powered workflows, 
reducing time-to-value from 45 days to 12 days and increasing 
activation rate from 52% to 82% by Q3 2026"

Select all that apply:
☑ Specific work described (redesign + AI workflows)
☑ Clear metrics with before/after (45→12 days, 52%→82%)
☑ Deadline included (Q3 2026)
☑ Bespoke to this situation

Feedback: "All of them! This is an excellent JTBD."
```

**Scoring:**
- 5/5 correct: "⭐ Pattern Master! You've got the eye."
- 3-4/5: "Good work! You're spotting the patterns."
- 0-2/5: "Keep learning. Review the examples again."

### Core API Function

**Create this helper function first:**

```javascript
async function invokeAgentAI(prompt, model = 'claude-sonnet-4') {
  try {
    const response = await fetch('https://api-lr.agent.ai/v1/action/invoke_llm', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${process.env.AGENT_AI_API_KEY}`,
      },
      body: JSON.stringify({
        instructions: prompt,
        llm_engine: model,
      }),
    });

    // Handle HTTP errors
    if (!response.ok) {
      const errorText = await response.text();
      throw new Error(`Agent.ai API failed: ${response.status} - ${errorText}`);
    }

    const data = await response.json();
    
    // Check for errors in 200 responses
    if (data.response && data.response.startsWith('Error:')) {
      throw new Error(data.response);
    }

    return data.response;
    
  } catch (error) {
    console.error('Agent.ai error:', error);
    
    // User-friendly fallback message
    return {
      error: true,
      message: "AI assistant is temporarily unavailable. You can continue manually or try again."
    };
  }
}
```

### Retry Logic (Optional but Recommended)

```javascript
async function invokeWithRetry(prompt, model = 'claude-sonnet-4', maxRetries = 2) {
  for (let i = 0; i < maxRetries; i++) {
    try {
      const result = await invokeAgentAI(prompt, model);
      if (!result.error) return result;
      
      // If error, wait before retry
      if (i < maxRetries - 1) {
        await new Promise(resolve => setTimeout(resolve, 1000 * Math.pow(2, i)));
      }
    } catch (error) {
      if (i === maxRetries - 1) {
        return { error: true, message: "Failed after retries" };
      }
    }
  }
}
```

### Rate Limiting (Client-Side Debouncing)

**To avoid excessive API calls:**

```javascript
// Debounce function
function debounce(func, wait) {
  let timeout;
  return function executedFunction(...args) {
    const later = () => {
      clearTimeout(timeout);
      func(...args);
    };
    clearTimeout(timeout);
    timeout = setTimeout(later, wait);
  };
}

// Use in Mode 2 real-time validation
const debouncedValidation = debounce(async (text) => {
  const feedback = await validateJTBD(text);
  displayFeedback(feedback);
}, 1000); // Wait 1 second after user stops typing

// In your input handler
inputField.addEventListener('input', (e) => {
  debouncedValidation(e.target.value);
});
```

### Storage Functions:

```javascript
// Save progress
function saveProgress(mode, data) {
  const storage = JSON.parse(localStorage.getItem('jtbdGame') || '{}');
  storage.progress = storage.progress || {};
  storage.progress[mode] = data;
  storage.progress.last_active = new Date().toISOString();
  localStorage.setItem('jtbdGame', JSON.stringify(storage));
}

// Save JTBD to library
function saveToLibrary(jtbdData) {
  const storage = JSON.parse(localStorage.getItem('jtbdGame') || '{}');
  storage.jtbd_library = storage.jtbd_library || [];
  storage.jtbd_library.push({
    id: generateUUID(),
    ...jtbdData,
    created: new Date().toISOString()
  });
  localStorage.setItem('jtbdGame', JSON.stringify(storage));
}

// Get user's JTBD library
function getLibrary() {
  const storage = JSON.parse(localStorage.getItem('jtbdGame') || '{}');
  return storage.jtbd_library || [];
}
```

## Accessibility Requirements

### WCAG 2.1 AA Compliance

**Color Contrast:**
- Text on white: Minimum 4.5:1 ratio
- Large text (18px+): Minimum 3:1 ratio
- Interactive elements: Clear focus states

**Keyboard Navigation:**
- All interactive elements reachable via Tab
- Clear focus indicators (2px outline)
- Logical tab order
- Enter/Space activate buttons

**Screen Reader Support:**
```html
<button aria-label="Go back to main menu">
  <svg aria-hidden="true"><!-- Icon --></svg>
</button>

<div role="alert" aria-live="polite">
  Score updated: 85/100
</div>

<progress 
  role="progressbar" 
  aria-valuenow="3" 
  aria-valuemin="1" 
  aria-valuemax="4"
  aria-label="Step 3 of 4">
</progress>
```

**Touch Target Size:**
- Minimum 44x44px for all interactive elements
- Adequate spacing between adjacent touch targets (8px minimum)

**Readable Text:**
- Minimum font size: 14px on mobile, 16px on desktop
- Line height: 1.5-1.8 for body text
- No justified text (causes uneven spacing)
- High contrast mode support

## Performance Optimization

### Load Time Targets
- First Contentful Paint: < 1.5s
- Time to Interactive: < 3s
- Total page weight: < 500KB (excluding AI API calls)

### Optimization Techniques

**Code Splitting:**
```javascript
// Lazy load mode content
const Mode1 = lazy(() => import('./modes/Mode1'));
const Mode2 = lazy(() => import('./modes/Mode2'));
const Mode3 = lazy(() => import('./modes/Mode3'));
```

**Image Optimization:**
- Use WebP format with PNG fallback
- Lazy load images below fold
- Responsive images with srcset
- Compress to < 100KB per image

**Animation Performance:**
```css
/* Use transform and opacity only (GPU-accelerated) */
.card {
  transition: transform 0.3s, opacity 0.3s;
  will-change: transform;
}

/* Avoid animating width, height, margin, padding */
```

**Minimize Repaints:**
- Batch DOM updates
- Use DocumentFragment for multiple insertions
- Avoid forced synchronous layout
